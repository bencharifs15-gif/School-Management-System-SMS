# 🏫 School Management System (SMS) - Système de Gestion Scolaire

## 🎯 Project Goals and Overview (Objectifs Principaux)

This repository contains the source code and documentation for the **School Management System (SMS)** project, developed using the **Agile Scrum Methodology**.

The primary objective is to create a comprehensive and secure digital platform to streamline administrative, academic, and communication processes within a modern school environment.

---

## ✨ Key System Features (Fonctionnalités Clés)

The SMS is designed to handle the core operations of the school, distributed across various user roles:

### 1. ⚙️ System Administration & Setup (Gestion Administrative)
| Role | Goal |
| :--- | :--- |
| **Admin** | Full control over system settings, academic year definition, and management of high-level user accounts (Admin/Registrar). |
| **Registrar** | Management of all operational data, including creating, updating, and deleting accounts for Teachers and Students. |

### 2. 📚 Academic Structure Management (Structure Académique)
* **Classes and Sections:** Ability to define and manage academic grade levels (`Grades`) and their sub-divisions (`Sections`) to form complete classes (`Class`).
* **Subjects:** Management and assignment of subjects (`Subjects`) to specific grade levels.

### 3. 📝 Score and Reporting Module (Suivi des Notes)
* **Grade Recording (Teacher):** Teachers can securely record and update student scores (`StudentScore`) for their assigned subjects (Use Case 8).
* **Grade Viewing (Student):** Students can access their full academic records and grade reports (Use Case 9).

### 4. 🔒 Security and Access
* Implementation of secure login/logout functionalities (UC12).
* Profile update capabilities for all authenticated users (UC13).
